# Tilal API

API تجريبي لموقع [التلال](https://github.com/huda0musallam/tilal-web)، مبني بـ json-server.

## التشغيل

```bash
npm install
npm start
```

بيشتغل على `http://localhost:3001`

## الروابط

| الرابط         | الطريقة | الاستخدام         |
| -------------- | ------- | ----------------- |
| `/products`    | GET     | المنتجات          |
| `/beans`       | GET     | أنواع البن للخلطة |
| `/reviews`     | GET     | آراء العملاء      |
| `/suggestions` | POST    | اقتراحات الزباين  |

البيانات محفوظة بملف `db.json`.
